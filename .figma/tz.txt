Общие требования
После окончания работ необходимо обеспечить возможность Заказчику самостоятельно вносить изменения (редактировать) в содержимое сайта.
По окончании работ требуется предоставить полностью функционирующий сайт, исходные графические материалы по дизайну, все необходимые данные для доступа к системе управления сайтом (аккаунты, пароли, адреса серверов и т.п.).
Требования к дизайну сайта
Дизайн должен быть выдержан в строгих и премиальных тонах. Использовать преимущественно графитовые и белые оттенки (графит #111214, белый #F5F5F3, серебристый металл) с одним акцентным холодным синим (электрик-голубым) цветом. Дизайн сайта должен быть выполнен с использованием языка HTML и CSS, при необходимости для создания анимаций и интерактивных элементов допустимо использование JavaScript.
Сайт должен корректно отображаться во всех современных браузерах.
Необходимо создать структуру (шаблон) сайта, состоящую из следующих элементов:
«шапка» (хедер). В данном блоке необходимо расположить логотип VORNE, меню главного сайта. Оно должно содержать перечень всех основных страниц (Модели, Конфигуратор, Технологии, Сервис, Дилеры). Требования к меню будут изложены далее. Меню должно поддерживать иерархическую структуру, дочерние элементы меню (например, отдельные модели в разделе «Модели») должны быть «выпадающими» (данный эффект необходимо создать с использованием языка JavaScript);
Блок для входа зарегистрированных пользователей на сайт («Войти» / личный кабинет);
«подвал» (футер) сайта. В данном блоке необходимо разместить краткую контактную информацию о бренде, а также контакты дилерской сети;
Блок отображения различного рода графической информации (баннеры с моделями автомобилей, промо-изображения и т.п.). Данные блоки могут добавляться по мере необходимости.
Требования к функциональности сайта
Необходимо обеспечить возможность предоставлять пользователям информацию на английском и русском языках. Пользователь должен иметь возможность сменить локализацию (язык) сайта.
Сайт должен позволять пользователям:
осуществлять навигацию по сайту (переход между страницами);
выполнять вход на сайт как зарегистрированный пользователь для возможности сохранения конфигураций автомобилей и заявок (при наличии соответствующих прав доступа).
Система управления сайтом должна позволять:
управлять страницами сайта (добавлять, удалять, изменять их содержимое);
управлять элементами меню;
добавлять/удалять баннеры с моделями автомобилей на сайте;
загружать на сайт графический материал (фото-видео изображения моделей, различные файлы и т.п.);
управлять параметрами конфигуратора (цвета кузова, отделки салона, комплектации, опции).
Требования к содержимому сайта
Необходимо создать следующие страницы сайта:
главная страница сайта;
страница «О бренде»;
страница «Контакты»;
страница «Модели»;
страница «Конфигуратор»;
страница модели;
страница входа зарегистрированных пользователей на сайт.
Необходимо создать меню навигации по сайту. Меню должно состоять из следующих элементов:
Главная страница
Модели
Конфигуратор
О бренде
Контакты
Детальное описание страниц сайта
Главная страница
В начале данной страницы необходимо вставить вводную информацию, описывающую позиционирование бренда VORNE.
Ниже вводной информации необходимо разместить информацию о бренде VORNE. Информация будет предоставлена дополнительно.
Ниже информации о бренде необходимо разместить информацию о модельном ряде, которым занимается «VORNE». Список моделей будет предоставлен дополнительно.
На главной странице сайта, а также на всех остальных страницах сайта, в «футере» (подвале) страницы необходимо разместить краткую контактную информацию и информацию о правообладании сайтом (авторском праве). Контактная информация будет предоставлена дополнительно.
Страница «О бренде»
На данной странице необходимо разместить краткую информацию о бренде VORNE. Необходимая информация будет предоставлена дополнительно.
Ниже краткой информации о бренде необходимо разместить изображения сертификатов качества и наград. Необходимые изображения будут предоставлены дополнительно.
Страница «Контакты»
На данной странице необходимо разместить контактную информацию (адреса дилерских центров, телефоны и т.п.). Контактная информация будет представлена дополнительно.
Страница «Модели»
На данной странице необходимо разместить баннеры с моделями автомобилей, содержащие название модели, фотографию, цену «от», краткое описание. При нажатии на баннер должен происходить переход на страницу с подробной информацией о модели (карточку модели). Реализовать возможность размещения баннеров с моделями авторизованным пользователям.
Страница «Конфигуратор»
На данной странице необходимо разместить информацию о выбранной конфигурации автомобиля (модель, цвет, привод, отделка салона, опции), должна быть реализована возможность изменения параметров конфигурации и оформления заявки.
Страница модели
На данной странице необходимо разместить подробную информацию о выбранной модели, фотоматериал, документы (технические характеристики, брошюра). Должна быть реализована возможность перехода к конфигуратору выбранной модели. Информация о модели будет предоставлена дополнительно.
Страница входа на сайт
На данной странице должна быть возможность зарегистрированным пользователям заходить на сайт. После входа пользователя на сайт, ему должны назначаться соответствующие права на доступ к определенной информации. Зарегистрированный пользователь сможет сохранять конфигурации автомобилей и отслеживать статус заявок.
Регистрировать пользователей на сайте и назначать им соответствующие права должен только администратор сайта.
